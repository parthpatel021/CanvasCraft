# CanvasCraft

CanvasCraft is a React-based drawing application that allows users to create shapes and lines on a canvas using intuitive mouse interactions. The application includes a toolbar for easy and efficient tool selection, enabling a smooth drawing experience.

CanvasCraft also supports session sharing for real-time collaboration. Users can generate a session link to invite others to join the same drawing session, encouraging teamwork and creative collaboration.
